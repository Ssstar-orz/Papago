# PAPA GO Hackathon Demo

纯 HTML/CSS/JavaScript 的关系语言与自我觉察 Demo。默认不接模型、不自动保存敏感输入；结果只由用户亲自填写和选择的内容生成。可选的服务端 AI 接口用于“第二次翻译”，没有密钥、断网或超时时会自动使用本地演示模板，并在结果上标明来源。键盘输入默认只留在页面；只有用户主动勾选 AI 生成后，已确认的内容才会发送给配置的 AI 服务。语音输入由浏览器提供，部分浏览器可能把音频发送给在线识别服务，页面会在麦克风旁持续提示这一点。

直接双击 `index.html`，或运行：

```powershell
node server.js
```

打开 `http://localhost:3000`。端口占用时可设置 `$env:PAPAGO_PORT=3001` 再启动。刷新页面会清空本轮内容。

主链路：可选 30 秒呼吸 → 填入案例 → 区分已经发生的事与脑中想法 → 感受身体 → 听见需要与保护冲动 → 编辑翻译卡 → 表达 / 暂停 / 不谈。表达分支会先选择 TA 更容易接住的沟通方式，再按沟通目的完成“第二次翻译”；暂停和不谈之后可以进入“冲动想守住什么 → 我怎样看待自己 → 此刻需要什么”的三步自我觉察。表达和自我觉察入口都会先经过主动安全确认。

## 可选 AI 接入

不使用 AI 时直接运行即可。需要现场展示 AI 时：

```powershell
Copy-Item .env.example .env
# 在本机打开 .env，填写 OPENAI_API_KEY；不要把真实密钥发到聊天或提交到仓库
node --env-file=.env server.js
```

页面中勾选“尝试用 AI 完成第二次翻译”。服务端使用 Responses API，并设置 `store: false`；密钥不会发送到浏览器。`OPENAI_MODEL` 可在 `.env` 中调整。无论 AI 是否成功，现场主链路都不会中断。
