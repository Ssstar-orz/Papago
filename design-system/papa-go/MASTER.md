# PAPA GO · Quiet Translation

这套语言来自对 Pi 实时页面的计算样式抓取，但只借系统，不借品牌资产。观察到的底色是 `#FAF3EA`，主要深绿是 `#1A4631`，交互绿是 `#038247`，正文使用 DM Sans；KIMI 文档里的陶土橙和漂浮光斑不是当前 Pi 页面的主视觉，因此不沿用。

界面是一间位于“冲动”和“行动”之间的安静房间。暖纸色降低关系冲突的温度，森林绿只标记行动权，不标记谁是正确的。开场的呼吸圆用于把注意力带回此刻，右上角折起的“翻译卡”把原话拆成已经发生的事、脑中想法、感受、身体反应、需要和保护冲动。具体中文规则见 `LANGUAGE.md`。

## Token

| 边框 | `#E1D3C0` / `#D9C9B4` |
| 主行动 / 焦点 | `#1A4631` / `#038247` |
| 危险入口 | `#A43C32` |

规则：每次只问一个问题；三条行动路径同权；暂停和不谈仍能继续向内探索；只用低透明暖棕阴影；结构化结果必须可改；语音入口旁必须持续说明浏览器可能进行在线识别；不使用陶土橙、粉色化、AI 紫色光晕、漂浮渐变光斑、Emoji 图标、Pi Logo 或专有资产。
