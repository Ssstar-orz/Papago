# PAPA GO 中文语言原则

PAPA GO 的“翻译”不是把用户的话修饰得更讨喜，而是让她先听见自己，再决定是否让对方听见。语言本身就是产品功能。

## 四条底线

1. **先承接，再发问。** 先说明“不必马上想通”“说不清也可以”，再邀请用户观察；不连续审问。
2. **说自然中文。** 使用“什么对你来说很重要”，不用“这件事碰到了你的什么需要”这类英文句式。
3. **保留解释权。** 使用“也许”“像是”“是否接近”，不说“你其实是”“你的身体已经知道”“这说明你属于某种人格”。
4. **先觉察，后行动。** 暂停以后先看冲动在守住什么、用户怎样看待自己，最后才出现可选的照顾方式。

## 不使用的表达

| 不使用 | 改为 |
|---|---|
| 身体哪里最有感觉？ | 先停一会儿，感受你的身体。 |
| 这件事碰到了你在意的什么？ | 在这件事里，什么对你来说很重要？ |
| 身体比大脑更先知道答案 | 身体的反应也可能提供一些线索。 |
| TA 是敏感型 / 回避型 / 吃软不吃硬 | TA 更容易接住哪种表达？ |
| 你是在用攻击保护自己 | 这股冲动也许是在替你守住什么。 |
| 你应该…… | 如果愿意，你可以从这些选择里找一个更接近的。 |

## 语气校验

- 删除可以套在任何疗愈产品上的空话。
- 不要求用户温柔、原谅、共情或安抚对方。
- 不为了让对方“听得进去”而删掉用户的边界。
- 一句话只做一件事；标签负责命名，说明负责解释，按钮说明点击后的动作。
- AI 生成内容必须可编辑，并明确标注来源；规则模板不能伪装成 AI。
